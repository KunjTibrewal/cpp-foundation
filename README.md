# My C++ Learning Journey

Started learning C++ in May 2026 and decided to document my progress through projects instead of only solving isolated problems.

## 1. Arrays → Student Management System

After learning arrays and loops, I built my first major project:

### Student Management System

Features:

* Student records
* Percentage calculation
* Grade assignment
* Class topper
* Subject-wise toppers
* Pass percentage calculation

At this stage I had not learned structures or functions yet, so all data was managed using arrays and most of the logic existed inside `main()`.

This project helped me understand how real-world data can be stored and processed using arrays.

---

## 2. Functions + Structures → Banking Management System

After learning:

* Functions
* Function Prototypes
* Structures

I revisited larger projects.

### Banking Management System

Features:

* Customer registration
* Password authentication
* Deposit & withdrawal
* Balance inquiry
* Account locking after repeated incorrect passwords

Unlike my first project, this version was organized into multiple functions and used structures to represent customers, making the code significantly easier to manage.

---

## 3. Applying Concepts at Scale → Library Management System

To become comfortable with functions and structures, I built a much larger project.

### Library Management System

Features:

* Member registration and login
* Librarian administration panel
* Book inventory management
* Borrow and return system
* Fine calculation
* Membership activation/deactivation
* Search by title, author and genre
* Unique ID management

While building this project I encountered and fixed several real programming problems:

* Duplicate ID generation
* Invalid lookups after deletion
* Input validation issues
* State consistency bugs
* Session flow bugs
* Inventory management edge cases

This project taught me more about debugging and program design than any tutorial.
